# Data Dictionary

| Column | Description |
|---|---|
| age | Customer age |
| income | Annual income |
| employment_years | Years employed |
| debt | Current debt |
| loan_amount | Requested/current loan amount |
| credit_history_years | Length of credit history |
| num_loans | Number of active/past loans |
| late_payments | Number of late payments |
| credit_utilization | Credit utilization ratio from 0 to 1 |
| savings | Approximate savings |
| employment_status | Employed, Self-employed, or Unemployed |
| payment_history | Excellent, Good, Average, or Poor |
| creditworthy | Target: 1 = creditworthy, 0 = not creditworthy |
